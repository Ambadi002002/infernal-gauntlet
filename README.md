# INFERNAL GAUNTLET: 100 HELLS
Hardcore 2-Player Precision Competitive Action-Platformer

## Features:
- **100 Scaled Procedural Gauntlet Levels:** Deterministic seed generation with exponentially scaling saw blade velocities, pulsing laser corridors, auto-turrets, vanishing platforms, and high-tier Fog of War (Level 30+).
- **Core Competitive Catch:** Only one player can win a level. You must survive ruthless obstacle hazards while assassinating the other player with melee combos, plasma bolts, or dash maneuvers.
- **Zero External Assets:** 100% Canvas graphics + procedural Web Audio API SFX engine.
- **Real-Time Multiplayer:** Built on Node.js + Express + Socket.io with room code matchmaking, client-side prediction, and event reconciliation.

## Quickstart Instructions:
1. Extract the zip archive.
2. Open terminal in the project directory:
   ```bash
   npm install
   npm start
   ```
3. Open `http://localhost:3000` in two separate browser windows or devices.
4. Player 1 hosts a lobby, copies the 5-letter Room Code.
5. Player 2 pastes the room code and joins.
6. Both hit **TOGGLE READY** to begin the descent into Hell.
